# Third-party notices

## Runtime dependencies

MoonKeyguard imports only `moonbitlang/core` packages supplied by the MoonBit
toolchain. The project does not vendor or copy implementation code from another
repository.

## Policy references

The reservation catalog contains short descriptions of common Windows, macOS,
Linux/POSIX and keyboard accessibility conventions. These are policy notes, not
copied source code or product assets. Each `ReservedRule` carries a human-readable
`source` field so downstream projects can replace or review the catalog before
using it in a release gate.

## Fixtures and generated files

The sample keymaps in `examples.mbt` and tests are original, minimal fixtures.
`pkg.generated.mbti` is generated by `moon info` from this repository's public
API and is not hand-authored source.
